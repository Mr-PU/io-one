PRASHANT UPADHYAY - THE ILLUSION OF ONE (author website)

WHAT'S INSIDE
- index.html   The complete website. Everything (design, code, cover, photo, gallery)
               is built into this one file, so it works on its own.
- assets/      Copies of your images for reference or future edits.

HOW TO PUT IT ONLINE (easiest options)
1. Netlify: go to app.netlify.com/drop and drag this whole folder onto the page.
   Then add your domain prashantupadhyay.in under Domain settings.
2. Cloudflare Pages or GitHub Pages also work: upload index.html.
3. Existing hosting (cPanel/WordPress host): upload index.html to the site's
   public_html folder (back up the old site first).
